# Attacker vs Defender —   The system i chose was my discord account

## The system
Discord is a application where people or friends chat together, call together in order to play games. it can also be used by an organisation.

## Attacker view
a typical attack i would see on discord which almost happends everyday would be phishing. since a lot of trading between players happens on discord a lot of traders would put unusally good trades in order to trick the player into taking the deal. once the person accepts the deal the attacker would send a phishing link. it would usually look like something like this WWVV.http-roblox.com or something in order to trick the person into clicking it. They would get access to my account if i clicked the link.

## Defender view
my defence is 2FA since even if they got access to my account they would need to verify that they own this account and i would change my password so they wouldn't know my password anymore. 2FA basically gives you 2 identification methods before giving you access to the account. the attacker would most likely have to give up since i have 2FA enabled and i would have changed my password so he would have to give me the link again in hopes i click it. a weakness to my 2FA would probably be if i logged in to attacker controlled site, since 2FA would just let them have access since i gave them the code so that would be useless and before i could change my password they would probably do it faster then me.
